How it works

  1. Decode. Your browser reads the GIF, rebuilds every full frame, and shrinks it to the chosen width (each character cell is twice as tall as it is wide).
  2. Convert. The most common border color is treated as the background and dropped. Every other pixel becomes a character from .:-=+*#%@, denser the further it is from the background, in its own 24-bit color.
  3. Export. The preview and the GIF draw each character from the same 6×12 pixel font. The player is a single Node script that plays the frames in your terminal.

Use it from the command line

The same conversion runs as two Node scripts that use ffmpeg. Requires Node 18+ and ffmpeg/ffprobe on your PATH.

git clone https://github.com/eimaj/gif2ascii2gif.git && cd gif2ascii2gif
node gif2ascii.mjs https://media.tenor.com/1iOUXZFLpBgAAAAM/dance-dancing.gif --width 40
node players/dance-dancing.mjs
node ascii2gif.mjs players/dance-dancing.mjs --scale 2
